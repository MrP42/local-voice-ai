# Local Voice AI 0.29.1 (Hotfix)

Stand 25.11.2026. Hotfix auf 0.29.0: nur Fehlerbehebungen, keine neuen Funktionen, keine Änderung an der Datenbank. Windows und macOS.

## Abo-Anbindung von Claude Code und Codex

Claude Code und Codex lassen sich in der App sichtbar einrichten oder auswählen, ohne Skript. Schlägt ein Schritt im Gespräch fehl, nennt die App den konkreten Grund statt einer allgemeinen Meldung (lva#831, #853).

## Modelldownload hinter einem Proxy

Scheitert ein Modelldownload, nennt die Meldung den Server und ob der Proxy die Ursache ist (lva#864, #865).

## Besprechungen: kein Transkriptblock geht mehr still verloren

Ist die Datenbank kurz belegt, wird ein Transkriptblock nicht mehr verworfen, sondern nachgeholt. Der Hinweis dazu erscheint nur noch, wenn wirklich etwas fehlt (lva#863, #866).

## Updates nicht mehr während einer Aufnahme

Das Update-Fenster öffnet sich nicht mehr von selbst, wenn beim Prüfen ein Diktat oder eine Besprechungsaufnahme läuft. „Installieren“ lädt sofort herunter und prüft vor dem Installieren erneut: Läuft eine Aufnahme oder lässt sich das nicht feststellen, wartet die Installation. Vorlesen und Anrufe werden dabei noch nicht berücksichtigt (lva#869).
