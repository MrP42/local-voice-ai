# Local Voice AI 0.28.0

Stand 19.11.2026. Nur Windows.

## Proxy-Anmeldung mit dem Windows-Konto (Negotiate/NTLM)

Verlangt der Firmenproxy eine Anmeldung (HTTP 407), meldet sich Local Voice jetzt mit dem angemeldeten Windows-Konto an (Negotiate, sonst NTLM). Es wird kein Kennwort abgefragt und keines gespeichert. Das gilt für alle Verbindungen ins Internet: Cloud-Anbieter (Modelle laden, Chat), Updates, Kalender und Integrationen, Modell-Downloads.

- Local Voice fragt den Proxy zuerst ohne Anmeldung und meldet sich nur bei einer Anmeldeaufforderung an; Ziele, die der Proxy ohne Anmeldung durchlässt, bleiben unverändert.
- Technisch läuft die Anmeldung über einen kleinen lokalen Weiterleitungsdienst im Programm (nur auf diesem Rechner erreichbar, durch ein zufälliges Kennzeichen geschützt). Lokale Dienste auf diesem Rechner gehen nie über den Proxy.
- Proxys mit Kennwortabfrage (Basic) und `https://`-Proxys werden nicht umgestellt; ein Proxy mit eigenen Zugangsdaten in der Einstellung bleibt, wie er ist.
- Die Fehlermeldung bei einer Proxy-Anmeldung nennt jetzt den tatsächlichen Zielhost (z. B. api.anthropic.com) statt fest Hugging Face.
- Bekannte Einschränkung: Ein fest eingetragener Systemproxy ohne PAC-Datei wird noch ohne Windows-Anmeldung angesprochen (lva#641).

## Speicherschutz sperrt kleine Diktatmodelle nicht mehr

- Auf einem 16-GB-Firmenrechner mit viel belegtem Arbeitsspeicher war kein Diktatmodell ladbar. Modelle bis etwa 1,1 GB (Diktat) werden jetzt trotz überschrittener Grenze geladen, solange sie in den Arbeitsspeicher passen; Local Voice meldet es einmal dezent.
- Neue Standardgrenze: 98 % (bisher 90 %). Wer die Grenze selbst geändert hat, behält seinen Wert; der alte Standard 90 % wird beim Update einmal auf 98 % angehoben.
- Alle Speicherprüfungen (Diktat, Vorlesen mit Phonon und Fish, Sprachmodell, Kalender) nutzen dieselbe Logik und dieselbe Einstellung; bei ausgeschaltetem Speicherschutz wird nie gesperrt. Große Modelle brauchen weiter genug freien Speicher (Notgrenze 2 GB frei).
