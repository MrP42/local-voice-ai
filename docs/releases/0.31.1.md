# Local Voice AI 0.31.1 (Hotfix)

Stand 26.11.2026. Hotfix auf 0.31.0: Fehlerbehebungen und kleine Verbesserungen, keine Änderung an der Datenbank. Windows und macOS.

## Update-Fenster

Das Update-Fenster nennt Hotfixes als solche und zeigt die Liste der Änderungen. Läuft gerade eine Aufnahme, ein Vorlesen oder ein Anruf, wartet die Installation sichtbar bis zum Ende. Nach dem Neustart meldet die App kurz, auf welche Version sie aktualisiert wurde (lva#869, #931).

## Nach dem Update sichtbar starten

Wer ein Update über „Jetzt installieren“ bestätigt, sieht die App nach dem Neustart im Vordergrund, auch wenn „Minimiert starten“ eingeschaltet ist. Der Autostart bei der Anmeldung bleibt minimiert (lva#869, #939).
