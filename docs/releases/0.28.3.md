# Local Voice AI 0.28.3

Stand 19.11.2026. Nur Windows.

## Besprechungen: keine hängende „Vorbereitung“ mehr

In 0.28.2 konnte beim Öffnen einer abgeschlossenen Besprechung eine Karte „Vorbereitung“ erscheinen, die sich nicht stoppen ließ (Meldung „Die Verarbeitung ist inzwischen beendet“). Ursache war die Folienerkennung im Hintergrund: Endete ein Lauf sofort wieder, löste das Ende den nächsten Start aus. Jetzt gilt:

- Die Hintergrund-Folienerkennung startet je Besprechung höchstens dreimal je Sitzung; danach wird sie beendet und Local Voice meldet es.
- Meldet das Programm beim Stoppen, dass es keinen laufenden Auftrag mehr gibt, verschwindet die Karte sofort.
- Die Anzeige wird alle 15 Sekunden und beim Zurückkehren ins Fenster mit dem tatsächlichen Stand abgeglichen; Einträge, die es nicht mehr gibt, werden entfernt.

Weiter in Arbeit: Hintergrundläufe beim bloßen Öffnen nur auf Wunsch, genauere Protokollierung (Kindprozesse, Fehler in der Warteschlange) und „wartet“ statt „Vorbereitung“ für zurückgestellte Läufe (lva#675).
