# Vorschau: Besprechungsnotizen (G8, #502)

Entwurf zur Abnahme vor der Umsetzung. `index.html` im Browser öffnen; die beiden Bilder zeigen
1280 px hell und 400 px dunkel.

Inhalt: sieben Bedienmuster aus der Granola-Erhebung (wai-sdk `docs/discovery/granola/`) und ihre
Übertragung auf Local Voice in fünf Ansichten (Start „Als Nächstes“, Notiz während der Besprechung,
Notiz danach mit Transkript, Anzeiger und Hinweise außerhalb des Fensters, iPhone).

Rahmen bleibt Fluent 2, Segoe UI, Microsoft-Palette. Beispieldaten sind erfunden.

Zur Abnahme gestellte Fragen:

1. Start „Als Nächstes“ ersetzt die Kacheln (klassische Startansicht bleibt wählbar).
2. Aufnahmen öffnen einspaltig; Projektbaum und Transkript klappen auf (dreispaltige Ansicht bleibt wählbar).
3. Leiste unten (Aufnahme-Kapsel und Frage) ersetzt die Reiter Notizen, KI-Notizen, Fragen.
4. Umschalter „Meine Notizen / Ausgearbeitet“ mit Zeitmarke je ergänzter Zeile.
