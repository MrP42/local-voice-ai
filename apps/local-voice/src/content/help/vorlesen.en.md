# Read aloud

Add text, choose an available voice and start playback. Speech is generated locally.

## Install only what you use

On macOS, the installed system voice is ready immediately and selected by default on a new setup. Additional read-aloud modules are optional. Under **Models → Reading voices**, download or remove Piper and individual voices. The first voice also installs its platform module. Voices appear in the selector only when their module is complete. If a selected voice is removed, choose another; the app does not silently switch voices.

## Text and playback

- Write, paste or dictate text.
- **Add (+)** opens documents, web addresses or project files.
- **Translate** and **Summarize** preserve the original and show results on separate tabs.
- Start, pause and move sentence by sentence.
- **Save audio** writes the result to the project folder.

Each page has its own text and folder. Double-click a page to rename it. Each text tab remembers its voice. Piper voices show language and quality in the selector.

## Fish Speech

Listen to, record, clone and import voices under **Settings → Read aloud**. Cloning needs a short reference recording with matching text.

Speaker changes such as **Olga:**, saved styles and expression tags work with Fish. The style palette and automatic tag suggestions help insert them.

The server icon shows the installed Fish runtime's state and offers start and stop. If startup takes too long, check available GPU capacity and the startup log.

## Settings and help

**Settings → Read aloud** contains volume, export and options for installed modules. The brain icon controls the language model for translation and summarization. Restore a missing voice through **Manage read-aloud modules**.
