# Vorschau: Stimme je Buchsprache (lva#352)

Stimmenauswahl im Reader, englisches Buch, Phonon.

| Bild | Zustand |
|---|---|
| `01-alle-buecher-1440-{light,dark}.png` | Wahl gilt für alle Bücher auf Englisch (Vorgabe). |
| `02-nur-dieses-buch-1440-{light,dark}.png` | Schalter „Nur dieses Buch“ an: eigene Stimme nur für dieses Buch. |

Zeile unter dem Sprachfilter im Kopf der Liste; Klick lässt die Liste offen.
Schalter: `role="switch"`, `aria-checked`. iPhone: gleiche Logik als Schalter
„Nur für dieses Buch“ oben in der Stimmenliste, Fußtext nennt die Sprache.
