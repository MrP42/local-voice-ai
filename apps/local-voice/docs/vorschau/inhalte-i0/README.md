# Vorschau Inhalte-Modul (Stufe I0)

Konzept: `docs/superpowers/specs/2026-11-12-inhalte-modul.md`. Statische HTML-Vorschau, keine App-Logik.

Aufruf: `vorschau.html?s=k|o|r` (Kurzfassung, Original, Routine), `&t=dunkel`, `&toast=1` (Meldung nach dem
Einfügen), `&baum=1` (390 px: Baum als eigene Ebene).

| Bild | Zeigt |
|---|---|
| `01-kurzfassung-*` | Baum links (Neu für dich, Projekte mit Gruppen, Ohne Projekt, Routinen), Kurzfassung „Das Wichtigste für mich“ mit Relevanz, Fristen/Terminen, Kernaussagen mit Belegen, Zahlen, Quelle; rechts Herkunft |
| `02-original-bereinigt-*` | formatierte Originalfassung (Überschriften, Tabelle, Hervorhebung beim Vorlesen), Liste der automatischen Bereinigungen, Meldung mit Rückgängig |
| `03-routine-*` | Routine „Intranet KI – täglich 6:00“ als Schrittfolge im Trockenlauf |
| `04-baum-390-*` | Smartphone: Baum als eigene Ebene |

Breiten 390/768/1440 (2560 nur Kurzfassung), hell und dunkel. Keine horizontale Body-Scrollleiste (geprüft).
Alle Inhalte synthetisch (`example.org`).
