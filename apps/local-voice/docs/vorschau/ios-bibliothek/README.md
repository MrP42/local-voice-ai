# Vorschau: Bibliothek auf dem iPhone (Epic #210)

UI-Vorschau zur Abnahme, noch kein App-Code. iPhone-Breite 390 pt, gerendert mit Faktor 2, je hell und dunkel.
Konzept: Bibliothek mit Vorlesen, Hören und Mitlesen in der nativen iPhone-App, synchronisiert mit dem Desktop
(Einträge, Fortschritt, Hörbuchdateien per verschlüsselter Hub-Dateiablage, Download bei Bedarf).

| Bild | Inhalt |
| --- | --- |
| `01-regal-*` | Neuer Tab „Bibliothek“ neben Sprechen und Transkripte: Suche, Filter, Karte „Weiterhören“, Cover-Raster mit Fortschritt; Haken = offline auf dem iPhone, Wolke = liegt im Konto, lädt beim ersten Öffnen |
| `02-buchseite-*` | Ein Eintrag mit Text und Hörbuch: Knöpfe Vorlesen und Hören, Fortschritt je Fassung mit Gerät der letzten Nutzung, Kurzbuch vom Desktop, Teile eines mehrteiligen Hörbuchs |
| `03-hoeren-mitlesen-*` | Hörbuch läuft, Text daneben, aktueller Absatz hervorgehoben und mitgescrollt (Zeitachse vom Desktop); Tipp auf Absatz springt; Player mit Tempo, ±15 s, Schlaftimer |
| `04-vorlesen-*` | Vorlesen mit iOS-Systemstimme: Absatz und gerade gesprochenes Wort hervorgehoben, Lesezeichen, Stimmenwahl |
| `05-download-sync-*` | Am PC hinzugefügtes Hörbuch wird beim ersten Öffnen geladen: Fortschritt, „Schon hören“ ab Teil 1, „Nur im WLAN laden“, Speicher, letzter Sync |

Beispieltexte: Kafka, „Die Verwandlung“ (gemeinfrei).
